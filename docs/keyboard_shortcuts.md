# Keyboard Shortcuts

Here is a list of all the keyboard shortcuts available in the editor.

> More keyboard shortcuts will be available in the future.

| Shortcut       | Description                   |
|----------------|-------------------------------|
| `Ctrl+N`       | Create a new project          |
| `Ctrl+O`       | Open a project                |
| `Ctrl+S`       | Save the project              |
| `Ctrl+Shift+S` | Save the project as a new one |
| `Ctrl+F4`      | Quit the editor               |
| `Ctrl+I`       | Open project details          |
| `F11`          | Toggles full-screen mode      |
| `Ctrl++`       | Zoom in                       |
| `Ctrl+-`       | Zoom out                      |
| `Ctrl+0`       | Reset zoom                    |
